# 柴胡

**疏解枢机要药、少阳病要药**。性微寒，辛苦，归 [[liver]]、[[gallbladder]] 经。

## 三大核心功效（覆盖三个方向）

### 疏散退热（治外感）
和解少阳半表半里证 → **小柴胡汤**主药。
- 寒热往来、胸胁苦满
- 默默不欲饮食、心烦喜呕
- 口苦咽干目眩

### 疏肝解郁（治肝郁）
治肝郁气滞 → **逍遥散**主药。
- 胸胁胀痛
- 情志抑郁
- 月经不调

### 升举阳气（治气陷）
治中气下陷 → **补中益气汤**主药。
- 久泻脱肛
- 子宫脱垂
- 胃下垂

## 「三柴胡」

同一味药、三个方向，体现中药的多功能性：
- **柴胡 + 黄芩** → 和解少阳
- **柴胡 + 当归白芍** → 疏肝养血
- **柴胡 + 升麻 + 黄芪** → 升提阳气
