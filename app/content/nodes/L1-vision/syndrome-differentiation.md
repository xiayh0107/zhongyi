# 辨证论治

中医的两大基本特点之一。

## 核心概念

- **症**：症状（个别表现，如头痛）
- **病**：疾病（西医名称，如高血压）
- **证**：证候（病机的高度概括，如肝阳上亢）

「证」是辨证论治的核心——同一个**证**有相同的病机和治法，无论它属于哪种**病**。

## 两条核心法则

### 同病异治
同一种疾病，因病邪性质不同、机体反应有异、所处阶段不同，**证不同 → 治法不同**。

例：感冒
- 风寒感冒 → [[ma-huang]] 等辛温解表
- 风热感冒 → [[lian-qiao]] 等辛凉解表

### 异病同治
不同疾病，只要病机相同（证相同），**治法相同**。

例：脱肛、子宫脱垂、胃下垂——病不同但都是「中气下陷」证 → 升提中气

## 辨证的方法
- [[eight-principles]] 八纲辨证（最基础）
- 脏腑辨证
- 气血津液辨证
- 六经辨证 / 卫气营血辨证 / 三焦辨证（外感病）
