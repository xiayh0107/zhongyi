# 气

气是构成人体和维持生命活动的最基本物质。

## 五大生理功能

| 功能 | 含义 | 异常表现 |
|---|---|---|
| 推动 | 激发促进生长发育、脏腑活动、精血津液运行 | 早衰、脏腑功能减退、精血生成不足 |
| 温煦 | 阳气发挥温煦作用，维持体温 | 畏寒肢冷、运行迟缓 |
| 防御 | 护卫肌表、防御外邪 | 易感冒、不易痊愈 |
| 固摄 | 固护、统摄液态物质（血/汗/尿/精）及脏器位置 | 出血、自汗、遗尿、滑精、内脏下垂 |
| 气化 | 通过气的运动产生各种代谢变化 | 代谢异常 |

## 气的运动（气机）

四种基本形式：**升 / 降 / 出 / 入**。

- 与气机升降最相关：[[lung]]（降）、[[spleen]]（升）
- 气机紊乱：气滞、气逆、气陷、气脱、气闭

## 五种基本气

| 气 | 来源 | 主要功能 |
|---|---|---|
| **元气**（原气、真气） | 肾中精气化生 | 推动生长发育和生殖、最根本的气 |
| **宗气** | 肺吸入清气 + 脾化生水谷精气 | 走息道司呼吸、贯心脉行气血。聚于胸中（膻中、气海） |
| **营气** | 水谷精微之精华 | 化生血液、营养全身 |
| **卫气** | 水谷精微之慓悍部分 | 防御外邪、司腠理开合、温养肌肤 |
| **中气** | 脾胃之气 | 维持中焦功能、升清降浊 |
