# 寒邪

寒为**阴邪**，最易伤阳气。寒邪伤肌表称「伤寒」，直中里伤脏腑阳气称「中寒」。

## 核心性质

### 寒为阴邪，易伤阳气

阳气受损，失其温煦气化作用，表现寒证：

- 寒邪袭表 → 卫阳被遏 → 恶寒、发热、无汗
- 寒邪直中太阴 → 损脾阳 → 脘腹冷痛、呕吐、腹泻

### 寒性凝滞

「寒主疼痛」—— 寒邪侵入致气血凝滞、运行不畅，多见疼痛症状。

### 寒主收引

寒邪使体内气机收敛，腠理、经络、筋脉收缩挛急：

- 寒袭表 → 皮肤腠理收缩、汗孔闭塞 → 恶寒、发热、无汗
- 寒客经络关节 → 筋脉牵引拘急 → 关节屈伸不利、拘挛作痛

### 寒性清澈

分泌物或排泄物呈清稀状（白色、无臭、量多）：清稀痰、清涕、清尿等。

## 与其他邪/脏的关系

- **寒邪 + [[kidney]]**：肾阳为一身阳之根，寒邪伤阳最伤肾阳（命门火衰）
- **寒邪 + [[spleen]]**：寒邪直中太阴最常见
- **风寒合邪**：典型"风寒感冒"
