# 湿邪

湿为**阴邪**，有形之邪，最易阻滞气机、损伤阳气。脾喜燥恶湿，湿邪最先困脾。

## 核心性质

### 湿为阴邪，易阻气机，损伤阳气

- 湿是有形之邪 → 阻滞气机 → 气机升降失常
- 湿邪类水属阴 → 损人阳气
- 困伤脾阳 → 胸闷、纳呆、脘痞腹胀
- 水湿停聚 → 腹泻、尿少、水肿、腹水

### 湿性重浊

**重**：临床表现沉重、重着：
- 湿袭肌表 → 周身困重、四肢酸沉怠惰
- 湿困于头 → 头重如裹、昏昏欲睡
- 湿留关节 → 肌肤不仁、关节疼痛重着不举（着痹）

**浊**：排泄物和分泌物秽浊不清：
- 湿浊在上 → 面垢眵多、苔腻厚
- 湿阻中焦 → 便溏不爽、下利黏稠脓血、小便混浊
- 湿浊下注 → 妇人带下黄白黏稠有秽臭
- 湿在皮肤 → 湿疹破溃、流脓渗水

### 湿性黏滞

- **症状黏滞**：大便黏腻不爽 / 小便涩滞不畅 / 舌苔黏腻
- **病程缠绵**：湿痹、湿疹、湿温等病，病程长、反复发作或时起时伏、缠绵难愈

### 湿性趋下，易袭阴位

- 湿性类水，水性润下 → 致病易伤机体下部
- 水肿多以下肢明显
- 湿邪下注之病：淋病、尿浊、带下、痢疾

## 与其他脏腑/邪的关系

- **湿邪 + [[spleen]]**：脾喜燥恶湿，湿最先困脾
- **湿热互结**：湿邪郁久化热，常见 → 湿热证
- **寒湿互结**：寒邪 + 湿邪，治宜温化寒湿
