# 火（热）邪

火（热）为**阳邪**，性炎上，致病迅猛剧烈。最易出血（六淫中最易出血者为火）。

## 核心性质

### 火为阳邪，其性炎上

常见高热、恶热、面赤、脉洪等症。症状多见于人体**上部**：

- 头痛、面赤
- 咽喉红肿热痛
- 齿衄、龈肿
- 口舌糜烂

### 火易扰心神

- 轻者：心神不宁、烦躁、失眠
- 重者：神不守舍、狂躁不安、神昏谵语

### 火易耗气伤津

阳胜则阴病：

- 热迫津液外泄 → 大汗 → 津液耗伤
- 热邪消灼煎熬阴津 → 口渴引饮、咽干舌燥、小便短赤、大便秘结
- 津伤气耗：体倦乏力、少气懒言
- 重者：气脱亡阴 → 阴损及阳 → 亡阳危象

### 火易生风动血

- **生风**：筋脉失养 → 肝风内动 → 高热神昏、四肢抽搐、颈项强直、角弓反张、两目上视（[[liver-wind-stirring]]）
- **动血**：各种出血证（吐血、衄血、妇女月经过多、崩漏等）

### 火热易致肿疡

火热侵入血分，可壅迫聚于局部，腐蚀血肉而发为**疮疡痈肿**。

## 与其他脏腑/邪的关系

- **火 + [[heart]]**：火扰心神，常见心火亢盛证
- **火 + [[liver]]**：火热生风 → 肝风内动；肝郁化火 → 肝火上炎
- **暑邪**：暑为火热之气，致病与火相似但多夹湿
