# 膀胱

「州都之官」。贮存和排泄尿液的器官。

## 主要功能

### 贮尿与排尿
- 水液经 [[kidney]] 气化后下输膀胱
- 在肾气推动下定时排出

## 与肾的关系

[[kidney]] 与膀胱**相表里**：
- 膀胱的开合（贮尿/排尿）依赖肾的气化
- 肾气虚 → 膀胱失约 → 遗尿、尿频
- 肾阳虚 → 气化无权 → 尿少水肿
