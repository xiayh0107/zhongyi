# 胃

胃位于中焦，与 [[spleen]] 同居中焦。「水谷之海」「太仓」。**喜润恶燥**（与脾喜燥恶湿相反）。

## 主要功能

### 主受纳，腐熟水谷
- **受纳**：接受、容纳饮食
- **腐熟**：饮食经胃初步消化，变成食糜
- 与脾运化配合 → 化生气血

### 主通降，以降为和
胃以**下降通畅**为顺。饮食入胃 → 下行小肠 → 大肠传糟粕。

胃气不降 → 嗳气、恶心、呕吐、呃逆等胃气上逆症状。
