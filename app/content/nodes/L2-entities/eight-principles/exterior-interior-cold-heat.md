# 表里寒热虚实

八纲中除阴阳总纲外的 6 个具体范畴。

## 表证 vs 里证（病位）

| 维度 | 表证 | 里证 |
|---|---|---|
| 起病 | 急 | 缓 |
| 病程 | 短 | 长 |
| 病位 | 浅（皮毛、肌肉、经络） | 深（脏腑、骨髓） |
| 恶风寒 | 恶风寒 | 无恶风寒 |
| 脉 | 浮 | 沉 |
| 舌苔 | 薄白 | 黄/白厚腻 |
| 典型 | 头身痛、鼻塞、咽痒、咳嗽 | 脏腑功能症状 |

## 寒证 vs 热证（病性）

| 维度 | 寒证 | 热证 |
|---|---|---|
| 原因 | 外感寒邪、阳气不足、阴寒偏盛 | 外感热邪、阳盛、阴虚 |
| 寒热感 | 恶寒喜暖 | 发热喜凉 |
| 口渴 | 口淡不渴 | 口渴喜冷饮 |
| 面色 | 苍白 | 红赤 |
| 四肢 | 冷蜷 | 烦躁不宁 |
| 二便 | 小便清长·大便稀溏 | 小便短赤·大便秘结 |
| 舌 | 淡 | 红 |
| 苔 | 白润 | 黄干 |
| 脉 | 迟 | 数 |

## 虚证 vs 实证（邪正盛衰）

| 维度 | 虚证 | 实证 |
|---|---|---|
| 病程 | 长 | 短 |
| 体力 | 消瘦无力 | 形体壮实 |
| 声音 | 低微 | 高粗 |
| 疼痛 | 隐痛喜按 | 拒按 |
| 二便 | 控制无力（自汗、遗尿） | 大便秘结、小便短赤 |
| 舌 | 改变（淡/瘦/胖嫩） | 苔厚腻 |
| 脉 | 无力 | 实有力 |
