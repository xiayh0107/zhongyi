# 产品哲学

> Fast Memory 是「工具」，不是「习惯机器」。它服务有明确目标的学习者，不试图制造日活。

## Why

绝大多数学习类 app 把"习惯养成"作为核心目标（多邻国是范例）。这套打法在零基础、低承诺的休闲学习者身上有效，但有两个副作用：

1. **机制冒充内容**：streak、徽章、push 通知制造"我在学习"的错觉，掩盖真实掌握度的不足
2. **强加节奏**：用 daily goal 把所有用户压缩到同一种学习模式，挫败那些自带动机但节奏不同的人

Fast Memory 的用户**自带动机**（考试、临床、研究、兴趣），他们需要的是「精准、可信、不打扰」的工具，不是哄他们坐下的玩具。

## 立场

### 工具，不是习惯机器

| 维度 | 习惯机器 | 工具 |
|---|---|---|
| 核心目标 | 让用户每天回来 | 让用户达成目标 |
| 反馈机制 | streak / 徽章 / 等级 | 知识状态可视化 |
| 推送策略 | 主动 push 催回 | 沉默，用户主动打开 |
| 成功指标 | DAU、留存 | 目标达成速度、需要时能回来 |
| 用户流失含义 | 失败 | 可能是成功（考完就走） |

### 信息密度 > 视觉糖

视觉化是放大器，不是必需品。第一版纯文字，先把"内容结构 + 检索闭环"做扎实，再渐进式叠加图、动画、交互可视化。**任何视觉化都必须能用一个具体的认知科学原理回答"为什么加它"。**

### 系统理解 > 题海

碎片刷题是行业默认做法（题库类 app），但它把知识网络拍扁成孤立点。Fast Memory 的差异化在「**先重构知识结构，再用检索练习巩固**」。题目是手段，理解结构才是目的。

## 谁是用户

按优先级：

1. **应试者**（首要 PMF）：医学院学生、执业考试备考者。目标明确、时间敏感、配合度高。
2. **临床执业者**：碎片时间复习、查阅。
3. **兴趣学习者**：节奏松散，但需要好的入口和系统性。
4. **转行/跨界学习者**：需要更多 L1 公理层的讲解。

**不服务**：完全零基础、纯娱乐探索者。这部分人是多邻国的目标，不是我们的。

## 不做什么（反模式清单）

- ❌ Daily streak / 连续打卡
- ❌ 每日学习目标 / 任务清单
- ❌ Push 通知催用户回来（除非用户主动设置提醒）
- ❌ 等级、徽章、皮肤等游戏化装饰
- ❌ 同伴对比 / 排行榜 / 社交压力
- ❌ "完成度"百分比（暗示有终点）
- ❌ 试错式学习（医学内容不能让用户瞎猜）
- ❌ 强制线性顺序（知识是网络，不是关卡）

每一条反模式背后都有具体理由，详见 [`design-principles.md`](design-principles.md) 和对应的 ADR。

## 北极星指标

**单一指标**：用户在「需要时」打开 app，能在 5 分钟内开始有效检索练习。

不是 DAU，不是留存率，不是平均使用时长。
